Detailed Description

The ten parameters of the paper's camera model: the intrinsics k = [d_x, alpha, d_y, u_p, v_p] (Eq.

13) followed by the Brown distortion coefficients xi = [k1, k2, k3, p1, p2] (Eq. 14), in that order.

Plain data with no ties to the command line or the pipeline, so the forward model can be evaluated at any parameter set. ProvideCameraParameters (providers/stage-providers.hpp) builds the prior from the CLI options.
