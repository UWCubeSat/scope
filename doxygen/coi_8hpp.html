Detailed Description

Center-of-intensity star centroiding kernel.

Implements the per-star centroid extraction described in the Orion paper (Christian et al. 2016, §"Image Processing and Star Centroiding", Eqs. 8-9): draw a ROI around the expected location, find the brightest pixel, recenter, mask the pixels within a small radius above a threshold, and take the intensity-weighted center of those masked pixels.

Extracts a single star centroid via center of intensity (paper Eqs.

8-9).

Steps:

  1. Define a roi_size x roi_size ROI centered on expected_pixel (clamped to the image bounds).
  2. Find the brightest pixel inside the ROI.
  3. Recenter on that brightest pixel.
  4. Build the mask of pixels within recenter_radius of the recentered point whose (dark-subtracted) intensity exceeds the threshold.
  5. Return the intensity-weighted center of the masked pixels.
Parameters
darkSubtractedSingle-channel, dark-frame-subtracted image. If the image has multiple channels, only the first channel is used.
expectedPixelThe expected star location [u, v] (column, row).
roiSizeThe ROI side length, in pixels (paper uses 31).
recenterRadiusThe mask radius about the brightest pixel (paper uses 3).
thresholdMinimum intensity for a pixel to join the mask.
Returns
The measured centroid [u', v'] (column, row), or std::nullopt if no pixel in the ROI exceeds the threshold.
Precondition
The caller has verified expected_pixel is in-sensor with adequate margin.
