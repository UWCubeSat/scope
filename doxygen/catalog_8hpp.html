Catalog scope::LoadBsc ( const std::string &  path)

Loads the Yale Bright Star Catalog (BSC, Vizier V/50) from a pre-filtered TSV.

The TSV is the output of download-bsc.sh: one star per line, pipe-separated as RA(deg)|Dec(deg)|HR|Multiple|Vmag, where Vmag is written as <high>.<low>.

Parameters
pathPath to the catalog TSV.
Returns
The parsed catalog. Each star's spatial vector is a unit vector built from its J2000 right ascension and declination.
Exceptions
std::runtime_errorif the file cannot be opened or no stars parse.
