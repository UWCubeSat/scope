Extracts one star centroid by center of intensity (paper Eqs.

8-9): find the brightest pixel in a ROI around the expected pixel, then take the intensity-weighted center of the pixels within recenterRadius of it that exceed the threshold.

An integer coordinate is the center of a pixel, as in FOUND: a star lit on the single pixel in column 40, row 30 centroids to exactly (40, 30). LOST's centroider adds 0.5, so subtract 0.5 from a LOST centroid before comparing.

Parameters
darkSubtractedDark-subtracted image. Only the first channel is used.
expectedPixelThe expected star location [u, v] (column, row).
roiSizeThe ROI side length, in pixels (paper uses 31). The ROI spans roiSize / 2 pixels either side of the rounded expected pixel, clamped to the image, so an even value acts as the next odd one.
recenterRadiusThe mask radius about the brightest pixel (paper uses 3).
thresholdIntensity a pixel must exceed to join the mask.
neighboursThe expected pixels of nearby stars. The search for the brightest pixel skips pixels strictly nearer one of them than expectedPixel; the mask is not restricted.
Returns
The measured centroid [u', v'] (column, row), or std::nullopt if no searched pixel exceeds the threshold.
