◆ AttitudeCorrection()

found::Quaternion scope::AttitudeCorrection ( const found::Vec3 &  dtheta)

The attitude correction for a small rotation vector dtheta (paper Eq.

11 and 38). To first order it is I - [dtheta x], so a camera-frame direction becomes e_C' = e_C + e_C x dtheta, and a corrected attitude is correction * attitude. It is computed exactly, as exp(-[dtheta x]), so the result is a rotation however large dtheta is.

Parameters
dthetaThe rotation vector, in radians.
Returns
The correction as a unit quaternion.

◆ LoadAttitudes()

std::vector< found::Quaternion > scope::LoadAttitudes ( const std::string &  path)

Loads one prior attitude per star image from a text file.

One quaternion per line, w x y z, separated by spaces, tabs or commas. Blank lines are skipped and # starts a comment. The k-th attitude belongs to the k-th star image.

Each quaternion must rotate an inertial (J2000) direction into SCOPE's camera frame (boresight on +z), as ProjectStarToPixel expects. Whatever writes the file does that conversion; for LOST it is LostAttitudeToScopeFrame.

Parameters
pathPath to the attitudes file.
Returns
The attitudes in file order, normalized.
Exceptions
std::runtime_errorif the file cannot be opened, or a line is not exactly four numbers or is the zero quaternion.
