Detailed Description

A set of star images: the camera that took them, where each was really pointing, and the attitudes a star tracker or plate solver reported.

The reported attitude is prior_k = E_k * misalignment^-1 * truth_k, with E_k a per-image error, so the correction a fit should find for image k, truth_k * prior_k^-1 = misalignment * E_k^-1, averages to the misalignment.
